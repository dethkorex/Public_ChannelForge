Your Plex URL and token stay on this computer. They are never bundled into exports.

For TVs or DVRs on another device, choose Local network and enter this computer's LAN URL. Restart ChannelForge after changing network access.

Automatic Plex token setup

In Plex Web, open any media item, choose Get Info → View XML, then copy the complete browser URL and paste it into Plex server URL. ChannelForge automatically extracts X-Plex-Token, saves it locally, and removes it from the visible URL. You may also enter the token manually.
