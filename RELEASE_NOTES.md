# ChannelForge Alpha 4.6.5

- The desktop TV Quality and Channel Order controls stay readable on Linux. Pressing Escape in a dropdown leaves playback active.
- Scan for Channels keeps the button and focus in place. The guide updates once the scan finishes and the mini-player continues playing.
- Windows and Linux Studio can recover a missing or rejected managed relay key from Retry connection using the existing Studio registration and assigned VPS route.
- The relay retires the previous key after the replacement carries a verified connection. Temporary network failures keep the existing key.
- Includes the Windows updater and empty-lineup startup fixes from Alpha 4.6.2 and 4.6.3.
