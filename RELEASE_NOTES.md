# ChannelForge Alpha 4.5.9

- Live TV and Rewind Cinema now request that supported Windows and Linux desktops stay awake during playback. Pausing a movie or stopping playback restores normal idle behavior.
- Fire TV, Android, and Roku keep the display awake while live channels or movies are playing or buffering. Pausing or exiting playback restores normal idle behavior.
- Fire TV and Android check the public release manifest when the GitHub API shows an older build. Signed APK verification still applies.
- Includes Alpha 4.5.8's full-page Arrange Lineup editor, movie and episode ordering by original release date, ten Up Next designs, and six new ambience tracks.
